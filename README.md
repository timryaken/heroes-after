# 《英雄之後》互動式前導原型

供內部溝通與操作測試使用的原生 HTML／CSS／JavaScript 原型。核心訊息是「因為有鏟子超人的幫助，光復已經恢復、重建得不錯，要不要回來看看」。內容從馬太鞍災後影像前導開始，進入記者子軒的一張擬真互動工作桌照片，桌上有電腦留言板、回訪手記、真實回訪地圖、三段原型訪談與合照。

## 本機啟動

在此資料夾執行：

```bash
python3 -m http.server 4173
```

接著開啟 `http://localhost:4173/`。不要直接雙擊 `index.html`，因為瀏覽器可能限制 ES modules。

## 建議展示流程

1. 播放或跳過前導，確認災後天數會從 `2025-09-23` 自動計算。
2. 選擇三種身分之一，桌景上方的大標題與副標會隨角色改變，祈願提問也會不同。
3. 桌機版點擊擬真桌景照片上的發光點；手機版向下瀏覽五張物件卡片。
4. 物件完成互動後，發光點會變成勾勾（只打開不算完成）：
   - 電腦：送出一則記憶或祈願。
   - 筆記本：翻到第 3 頁（`11/15` 同行邀請），把 Email 直接寫在筆記上。
   - 地圖：點開任一個地點（地圖點位或下方地點按鈕）。
   - 聲音：三段聲音都聽完。
   - 合照：點擊最上面那張照片（或左右箭頭）切換疊放的照片。
5. 聲音只有在按下某一段後才會播放；若裝置不支援系統語音，會直接顯示逐字稿並視為聽完。
6. 測試記憶、照片及祈願表單，確認成功訊息標示資料不會送出。

## 外部資源

- 回訪地圖使用 Leaflet 1.9.4（cdnjs）與 OpenStreetMap 圖磚，需連網；離線時會改顯示地點按鈕。
- 筆記本手寫字型為 Google Fonts 的霞鶩文楷 TC（LXGW WenKai TC）。

## 重設原型

從右上角「素材來源」開啟面板，按「重設這台裝置上的原型資料」。這只會清除本原型使用的 `heroes-after-prototype` localStorage 鍵，並重新開啟身分選擇，不會影響其他網站資料。

## 隱私與功能限制

- 這是無後端的內部原型；文字、Email 與探索進度只暫存在目前瀏覽器的 localStorage，不會寄信或傳送到伺服器。
- 選取的照片只建立本機預覽，重新整理後不保留，也不會上傳。
- 訪談內容與系統語音是原型示意，並非真實受訪者錄音。
- 子軒、搭檔與居民合照及桌面紋理為 AI 生成示意；不代表真實人物或新聞紀錄。

## 照片與來源政策

災害、志工及現況照片來自公開新聞報導，畫面內與「素材來源」面板均保留署名和原始報導連結。現階段僅限內部原型溝通；正式對外發布前，必須逐張重新確認著作權授權、使用範圍與署名方式。大同村今昔照片目前明確標示為原型暫代影像。

## 更換內容與素材

- 文案、角色標題、地點座標、來源、旁白：編輯 `js/data.js`。
- 圖片：把新檔案放進 `assets/images/`，並同步修改 `js/data.js` 的 `src`、`alt`、`credit`、`sourceUrl`。
- 合照疊放：編輯 `js/data.js` 的 `PHOTO_STACK`；`placeholder: true` 是灰色佔位圖，補照片時改成 `src` 與 `alt` 即可。
- 佛祖街今昔照片目前暫用車站志工與鏟子超人館照片，待換正式照片。
- 視覺：共用樣式在 `styles/base.css`，前導在 `styles/prologue.css`，桌景、筆記本、地圖與物件對話框在 `styles/desk.css`。
- 地圖行為：`js/map.js`；打勾條件串接在 `js/app.js`。
- 災害起算日：在 `js/core.js` 的 `daysSinceDisaster` 預設值修改。

修改後執行：

```bash
node --test tests/*.test.mjs
node scripts/check-static.mjs
```

靜態檢查會確認入口檔、五個物件、本機圖片、替代文字、署名與 HTTPS 來源網址。
